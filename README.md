# 小月历

移动端优先的经期日历 PWA。记录只保存在当前浏览器的 IndexedDB 中；首次使用没有演示经期，也不会自动生成实际记录。

## 本地运行

需要 Node.js 20.19 或更新版本。

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

## GitHub Pages

推送到 `main` 后，GitHub Actions 会运行测试、构建并发布到：

<https://yez780055-cell.github.io/xiaoyueli/>

Pages 项目路径由工作流中的 `VITE_BASE_PATH=/xiaoyueli/` 提供；本地开发与普通预览默认使用 `/`。Vite PWA 会将同一基础路径用于安装清单、图标、离线导航和 Service Worker。

开发服务可用于手机同一局域网预览。生产环境使用 HTTPS 后，可从安卓浏览器菜单将小月历添加到主屏幕；服务工作线程会缓存应用资源，支持离线打开。

## 记录与预测

- 点击「开始记录」后从当天开始，持续标记至今天；只有手动确认结束后才保存结束日期。
- 历史补录与编辑会校验日期顺序、未来日期和记录重叠。
- 预测日期使用浅紫色；实际经期使用粉色，并始终覆盖预测标记。
- 预测优先参考最近最多六个实际周期。历史不足时会明确标注；如果用户设置了参考周期，低样本预测会标明为参考估算。
- 统计图只展示实际记录；没有数据时显示说明，不填入虚构数据。

## 隐私与备份

- 无账号、无云同步。周期记录与关怀备忘默认只保存在设备浏览器。
- 备份文件必须设置独立密码，使用 PBKDF2-SHA-256（250,000 次迭代）派生 AES-GCM-256 密钥；没有明文导出入口。恢复前会先解密、校验日期冲突，再由用户确认替换本机数据。
- 应用锁用于日常遮挡访问，不是设备级加密。能访问浏览器配置文件或开发者工具的人仍可能读取本机数据库。
- 浏览器通知只在应用运行时尽力送达；纯 PWA 无法保证应用完全关闭时的定时通知。再次打开时会检查近期遗漏提醒。
- 清除所有数据需输入「清除」二次确认，并删除本机记录与设置。
